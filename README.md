Here several code and tools used in papers and secondary work

## SFEXIS

[SFEXIS — Strong Field Electron XUV Interaction Simulator](SFEXIS/README.md)
now has a dedicated project directory, a small runnable MATLAB example,
physics tests, and a [physics and implementation guide](SFEXIS/docs/GUIDE.md).
The original `Basic_SFEXIS_SourceCode` bundle is preserved in
[`SFEXIS/legacy`](SFEXIS/legacy), including its data and historical simulations.

**When using or adapting SFEXIS, credit Federico Vismarra and cite:**
F. Vismarra, R. Borrego-Varillas, Y. Wu, D. Mocci, M. Nisoli and M. Lucchini,
“Ensemble effects on the reconstruction of attosecond pulses and photoemission
time delays,” *Journal of Physics: Photonics* **4**, 034006 (2022),
[doi:10.1088/2515-7647/ac7991](https://doi.org/10.1088/2515-7647/ac7991).
The root [CITATION.cff](CITATION.cff) describes SFEXIS specifically; this citation
does not automatically apply to unrelated projects in this repository.
