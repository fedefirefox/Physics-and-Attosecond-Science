# Original SFEXIS source

**[SFEXIS v1.0.0 — release and downloads](https://github.com/fedefirefox/SFEXIS/releases/tag/v1.0.0)** is available in the dedicated [SFEXIS repository](https://github.com/fedefirefox/SFEXIS), with runnable MATLAB examples, physics and implementation documentation, tests, licensing and citation information.

This folder keeps Federico Vismarra's original SFEXIS MATLAB scripts, helper functions, data and saved simulations in place. The original files are unchanged and their history is preserved.
